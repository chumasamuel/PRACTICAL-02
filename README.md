Project Description

This project is a modern and responsive website designed for the Department of Computer Science at the University of Kerala.

The website provides information about the department, academic programmes, faculty members, research activities, laboratories, courses, and contact information. It is designed to provide students, faculty members, researchers, and visitors with an easy and attractive way to access information about the department.

Main Features: 

* Home page with department introduction
* About the Department section
* Academic programmes and courses
* Research areas
* Laboratory information
* Department activities
* Contact section
* Location/map
* Social media links
* Responsive navigation
* Responsive design for desktop and mobile devices

How to Run
Download or clone the project repository.
Open the project folder in Visual Studio Code.
Open index.html in a web browser.
Navigate through the different sections of the website.

Alternatively, the project can be opened using the Live Server extension in Visual Studio Code.

Requirements

To run this project, the following are required:

A modern web browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox.
Visual Studio Code (recommended for development).
Live Server extension (optional).
Purpose of the Website

The main purpose of this website is to create a centralized online platform for presenting information about the Department of Computer Science at the University of Kerala.

The website aims to improve accessibility of departmental information and provide visitors with information about academic programmes, courses, research, laboratories, and ways to contact the department.

Academic Context

The University of Kerala's official information lists Computer Science among its university departments and includes M.Sc. Computer Science and related postgraduate programmes. The department has also been associated with research areas including Artificial Intelligence, Machine Learning, Digital Image Processing, Computer Vision, Data Mining, Cyber Security, and other areas of Computer Science.
